本政策說明 MissionEngine 如何存取、使用、儲存、分享及保護 Google 使用者資料。MissionEngine 是由開發者自行架設的個人工具，不開放公開註冊，也不販售任何資料。

1．存取哪些資料

MissionEngine 只向 Google 要求以下兩項唯讀權限：

  • Gmail（gmail.readonly）：郵件寄件者、收件者、主旨、日期、摘要、內文、Gmail 標籤，以及附件的檔名、類型與大小等資訊。程式不會下載附件內容。
  • Google 日曆（calendar.readonly）：行程名稱、說明、時間、地點、與會者回覆狀態及重複規則。

MissionEngine 無法寄信、刪信或修改郵件，也無法建立、變更或刪除日曆行程。

2．如何使用資料

資料只用於提供 MissionEngine 給授權使用者的功能：

  • 判斷郵件是否需要注意，並篩除促銷與不重要的內容。
  • 將行程、期限與提醒放進每日規劃。
  • 將訂單、付款與物流通知對應到購買紀錄。
  • 整理需要使用者知道或決定的事項，並透過 Discord 通知。

3．如何儲存資料

郵件與日曆資料，以及由其產生的分類結果、規劃與購買紀錄，都儲存在開發者自行管理的私人伺服器資料庫中。Google OAuth 權杖也存放在同一台伺服器上，不會存入原始碼庫。

4．與第三方分享

資料只會為了提供上述功能，傳送給以下服務供應商：

服務傳送的資料用途
OpenAI需要 AI 判斷的郵件與行程內容（最多約 20,000 字元的內文），以及由其整理出的項目分類與整理內容
TypeSafe（Jev，typesafe.ai）寄件者、主旨及最多 800 字元的郵件摘要預先篩選郵件是否值得保留
Discord傳給使用者本人的摘要、提醒與問題傳送通知與接收回覆

除上述情況外，以及法律要求時，MissionEngine 不會將 Google 使用者資料提供給其他人。資料不會被出售，也不會用於廣告。第三方服務如何處理收到的資料，另受其各自的條款與政策規範。

5．Google API 服務使用者資料政策

MissionEngine 使用及傳輸從 Google API 取得的資訊時，遵守 Google API Services User Data Policy，包括其中的 Limited Use（有限使用）要求。

  • 只將資料用於提供或改善使用者可見的 MissionEngine 功能。
  • 不將資料用於廣告，也不出售資料。
  • 不用於開發、改善或訓練通用型 AI 或機器學習模型。
  • 除非取得使用者同意、為了安全目的或法律要求，否則不允許人員閱讀資料。

6．如何保護資料

  • 只要求唯讀權限，將可存取的範圍降到最低。
  • 與 Google、OpenAI、TypeSafe 及 Discord 的連線皆使用 HTTPS。
  • 資料庫、OAuth 權杖與 API 金鑰不存入原始碼庫，只保留在私人伺服器上。

沒有任何系統能保證絕對安全，但若發現影響資料的安全事件，開發者會通知受影響的使用者。

7．資料保留與刪除

資料會保留到不再需要、使用者要求刪除，或開發者手動刪除為止，目前沒有設定自動到期刪除。

使用者可以隨時前往 Google 帳戶權限頁面撤銷 MissionEngine 的存取權。撤銷後，MissionEngine 將無法再讀取新資料。如需刪除已儲存的資料，請透過下方的聯絡方式提出。

8．兒童

MissionEngine 不以兒童為服務對象，也不會刻意收集兒童的資料。

9．政策變更

本政策若有變更，會更新於此頁面並修改上方的日期。

10．聯絡方式

如有問題或要求刪除資料，請到 GitHub Issues 聯絡開發者，內容請勿包含個人資料。

This policy explains how MissionEngine accesses, uses, stores, shares and protects Google user data. MissionEngine is a personal tool hosted by its developer. It has no public sign-up and does not sell any data.

1. Data accessed

MissionEngine requests only these two read-only Google permissions:

  • Gmail (gmail.readonly): sender, recipients, subject, date, snippet, body and Gmail labels, plus attachment information such as file name, type and size. Attachment contents are not downloaded.
  • Google Calendar (calendar.readonly): event title, description, time, location, attendee response status and recurrence rules.

MissionEngine cannot send, delete or modify email, and cannot create, change or delete calendar events.

2. How data is used

Data is used only to provide MissionEngine features to the authorized user:

  • Deciding whether an email needs attention and filtering out promotions and unimportant messages.
  • Adding events, deadlines and reminders to the daily plan.
  • Matching order, payment and shipping notices to purchase records.
  • Preparing items the user should know about or decide on, and notifying the user through Discord.

3. How data is stored

Email and calendar data, along with the classifications, plans and purchase records derived from it, are stored in databases on a private server managed by the developer. Google OAuth tokens are stored on the same server and are never committed to source control.

4. Sharing with third parties

Data is sent only to the following service providers, and only to provide the features above:

ServiceData sentPurpose
OpenAIEmail and calendar content that needs AI judgment (up to about 20,000 characters of body text), and items derived from itClassifying and organizing content
TypeSafe (Jev, typesafe.ai)Sender, subject and an email excerpt of up to 800 charactersPre-screening whether an email is worth keeping
DiscordSummaries, reminders and questions sent to the userDelivering notifications and receiving replies

Other than these cases and where required by law, MissionEngine does not provide Google user data to anyone else. Data is not sold and is not used for advertising. Each provider's handling of the data it receives is also subject to its own terms and policies.

5. Google API Services User Data Policy

MissionEngine's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

  • Data is used only to provide or improve user-facing MissionEngine features.
  • Data is not used for advertising and is not sold.
  • Data is not used to develop, improve or train generalized AI or machine learning models.
  • People do not read the data unless the user agrees, or it is needed for security purposes or required by law.

6. How data is protected

  • Only read-only permissions are requested, which keeps access to a minimum.
  • Connections to Google, OpenAI, TypeSafe and Discord use HTTPS.
  • Databases, OAuth tokens and API keys are kept out of source control and stay on the private server.

No system can guarantee absolute security. If a security incident affects data, the developer will notify affected users.

7. Retention and deletion

Data is kept until it is no longer needed, the user asks for deletion, or the developer deletes it manually. No automatic expiry is currently configured.

Users can revoke MissionEngine's access at any time on the Google Account permissions page. After that, MissionEngine can no longer read new data. To delete stored data, use the contact method below.

8. Children

MissionEngine is not directed at children and does not knowingly collect children's data.

9. Changes to this policy

Changes will be posted on this page and the date at the top will be updated.

10. Contact

For questions or deletion requests, contact the developer through GitHub Issues. Please do not include personal data in your message.
